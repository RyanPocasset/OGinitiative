# Ell Pond Old-Growth Strata (field map)

Static Leaflet map of the Ell Pond / Long Pond old-growth sampling strata (Models A, B and C), sample points, and 0.5 m lidar micro-relief layers.
Pocasset Pokanoket Land Trust with RIDEM Division of Forest Environment.

Served as-is by GitHub Pages: Settings > Pages > Deploy from a branch > main / (root).
The page asks search engines not to index it, but anyone with the link can open it.
